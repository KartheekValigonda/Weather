# Weather APP

A Flutter project.

This is a sleek and modern weather application built using Flutter and Dart, designed with a impressive and intuitive UI for a seamless user experience. The app fetches real-time weather data using APIs, displaying current conditions, temperature, humidity, and forecasts for the user's location or searched cities. The user interface features dynamic visuals like weather icons, gradients, making it both functional and visually appealing. Ideal for showcasing Flutter's UI capabilities and API integration.
